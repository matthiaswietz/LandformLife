# Benthic biodiversity hotspots in the Weddell Sea

This repo contains the analytical workflow from "Benthic biodiversity hotspots in the Weddell Sea: Bridging geomorphology, biogeography, and oceanography across scales".   

Here, we study the connection between benthic biology, seafloor terrain, and hydrography on the steep flank of the Antarctic Powell Basin, from local to regional scales. 

To reproduce analyses and figures, please run scripts in the numbered order using [these datafiles](https://zenodo.org/records/18989285).
