# Benthic biodiversity hotspots in the Weddell Sea

This repo contains the analytical workflow from "Benthic biodiversity hotspots in the Weddell Sea: Bridging geomorphology, biogeography, and oceanography across scales". Here, Miao Fan and colleagues study benthic biology and their connection to terrain and hydrography from local to regional scales in the Southern Ocean. To reproduce analyses and figures, please run scripts in the numbered order, using the datafiles deposited under ZENODO.
