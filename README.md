# Benthic biodiversity hotspots in the Weddell Sea: Bridging geomorphology, biogeography, and oceanography across scales

This repo contains all scripts and data files from the study by Miao Fan and colleagues, studying benthic biology and their connection to terrain and hydrography from local to regional scales in the Southern Ocean.
