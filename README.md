# Benthic biodiversity hotspots in the Weddell Sea: Bridging geomorphology, biogeography, and oceanography across scales

This repo contains all scripts and data files from the paper "Benthic biodiversity hotspots in the Weddell Sea: Bridging geomorphology, biogeography, and oceanography across scales" by Fan and colleagues. Here, benthic biology and their connection to terrain and hydrography are studied from local to regional scales in the Southern Ocean. To reproduce analyses and figures, please run scripts under "" in the numbered order, using the datafiles in "".
