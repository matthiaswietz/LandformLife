# Benthic biodiversity hotspots in the Weddell Sea

This repo contains the analytical workflow from "Benthic biodiversity hotspots in the Weddell Sea: Bridging geomorphology, biogeography, and oceanography across scales". Here, Miao Fan and colleagues study the connection between benthic biology, seafloor terrain, and hydrography from local to regional scales. To reproduce analyses and figures, please run scripts in the numbered order, using the datafiles deposited under ZENODO.
